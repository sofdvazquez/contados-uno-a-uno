# contados-uno-a-uno
Contados uno a uno: bilingual interactive page on animals killed in Spain's slaughterhouses (2004–2026), built from official MAPA data. Data cleaning in Python (pandas), data visualisation.
Built with AI assistance (Claude). I chose the topic and the sources, downloaded and reviewed the official data, checked the results against the original files, and decided on the content and design. The AI helped write the cleaning code and the page.
